# 两仪 LiangYi（定制版）

基于 [twoyi/twoyi](https://github.com/twoyi/twoyi)（作者 weishu）的定制分支。

## 本分支改了什么

1. **品牌化**：App 名称显示为「两仪」，启动提示中文化，全新阴阳太极风格应用图标。
2. **在线下载 ROM（新增）**：设置 → 高级 → **「下载自定义 ROM」**，输入 7z ROM 的直链即可：
   - 自动尝试原始直链 + 多个公共 GitHub 加速镜像（含 `gh.luogen.cc.cd` 前缀），下载失败自动换源、每个源重试；
   - 本地已存在可用 ROM 时直接跳过下载、缓存复用；
   - 下载完成后自动重启安装（走两仪原生的第三方 ROM 机制）。
3. **云编译**：`.github/workflows/build.yml`，推送代码即自动编译 APK 并发布 Release。
4. **移除本地 Rust 编译依赖**：`libtwoyi.so`、`rootfs.7z` 在 CI 中从官方 0.5.4 发布 APK 自动提取。

## 保留的功能（不会因构建丢失）

两仪自带管理器与超级管理者（root 控制端）都位于内置 rootfs 镜像内。本分支**保留官方 8.1 rootfs 原样打包**，因此：
- 替换镜像 / 恢复出厂设置 / 关机 / 重启 等管理器功能全部保留；
- root 功能与授权管理保留；
- 导入第三方 ROM（本地文件或本分支新增的在线下载）后，管理器会被新 ROM 覆盖——新 ROM 需自带等价组件，这是两仪 ROM 格式的固有机制，无法在 App 层规避。

## 如实说明（重要，请务必阅读）

- **关于「安卓 9/10 精简镜像」**：两仪的 ROM（rootfs）源码从未开源，社区目前**不存在**可以直接在两仪中引导的安卓 9/10 rootfs。把 AOSP 安卓 10 镜像直接改造成两仪 rootfs 需要适配两仪的启动器（libloader/虚拟 HAL），不是替换文件就能完成的工程。本分支因此保留官方 8.1 镜像，并提供在线下载通道——一旦社区出现可用 ROM（7z 格式、含合法 rom.ini），即可直接下载安装。
- **系统兼容范围**：官方代码面向 Android 8.1~12。降低 minSdk 至安卓 7 会在运行时崩溃（代码使用了 API 26+ 的 java.nio.file 符号链接等能力）；安卓 13+ 上的卡死问题源于两仪使用的非公开接口在新系统上的变化，App 层无法根治。
- **流畅度**：滑动不跟手主要来自两仪的渲染管线（App 内模拟屏 + 输入转发），换镜像不会根治。可在两仪内打开开发者选项：关闭窗口动画缩放/过渡动画缩放/动画时长缩放（设为 0.5x 或关闭）、限制后台进程，可明显改善观感。后台切换卡死可在宿主系统设置中关闭两仪的电池优化、允许后台运行。

## 编译

推送即自动编译；也可本地执行（需 Android SDK）：

```
./gradlew assembleRelease
```
